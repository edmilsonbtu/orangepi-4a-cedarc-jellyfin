# Third-party components and licensing

## Project code

The project proposes the MIT license for original integration code
authored during its development.

The provenance of all included source files must be confirmed before
public redistribution. The LICENSE file does not override third-party
copyrights or licenses.

## Allwinner CedarC

The project uses external CedarC APIs and libraries, including:

- libvdecoder
- libvencoder
- libvideoengine
- libMemAdapter
- libVE

These vendor libraries are not included in the repository or package.

The user must obtain compatible libraries and development headers
through an appropriately licensed source.

## Jellyfin and FFmpeg

Jellyfin and FFmpeg are independent third-party projects.

Their respective licenses remain applicable. This repository does not
redistribute Jellyfin or FFmpeg binaries.
